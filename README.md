# Futures prop firm rules

Account rules for 14 futures prop firms (313 account sizes) in one JSON file:
profit targets, drawdown amounts and type, where the trailing drawdown stops, daily loss limits,
consistency rules, contract limits, payout requirements and list prices.

Last updated from each firm's own website: **2026-10-01**. The same data, with calculators for each plan, is at [tradeharbor.co/prop-firm-rules](https://tradeharbor.co/prop-firm-rules).

Firms change their rules often. Always confirm against the firm's current page (linked for every
plan below) before you rely on a number. Not affiliated with any firm listed. This is reference
data, not trading or financial advice.

## Files

- `prop-firm-rules.json`: every firm, plan and account size, plus the rule changes log.

## Fields

Each firm has `programs` (one stage of a firm's product: an evaluation, the funded account that
follows it, or a straight-to-funded account), and each program has `accounts`, one per size.

| Field | Meaning |
| --- | --- |
| `stage` | `eval`, `funded` or `direct` (straight to funded, no evaluation) |
| `source` | the firm's own page the numbers came from |
| `rules` | the firm's rules that don't fit a number, in plain words |
| `size` | account size in thousands of dollars |
| `startingBalance` | dollars; `0` where the funded account starts at $0 (`zeroStart`) |
| `profitTarget` | dollars of profit to pass; `null` for funded accounts |
| `maxDrawdown` | dollars below the high-water mark (trailing) or starting balance (static) |
| `drawdownMode` | `trailing_eod` (trailing, end of day), `trailing_trade` (trailing, intraday), `static` (static) |
| `drawdownLock` | the balance where a trailing drawdown stops trailing; `null` = it never stops |
| `dailyLossLimit` | dollars, `null` = none; `dailyLossHard`: hitting it fails the account rather than ending the day |
| `consistencyPct` | the best day's share of total profit that the firm allows, `null` = no rule |
| `minTradingDays` | days with a trade needed to pass, `null` = no minimum |
| `contracts` | max size as `minis/micros` |
| `payoutLock` | the first payout moves the drawdown straight to its lock level |
| `payoutLockAt` | the drawdown trails with no cap until the first payout, then locks here |
| `payout` | what a funded account needs before each payout: `buffer` (profit to hold above the start), `profitGoal` / `laterGoal` (cycle profit for the first / later payouts), `paths` (alternative day requirements, any one qualifies: `winDays` of at least `winDayMin`, `minDays`, payout `consistency`), `consistencySteps`, `everyDays`, `note` |
| `price` | list price: `billing` (`once` or `monthly`), `eval`, `reset`, `activation`; discounts are common |
| `activationFee` | dollars when the evaluation is passed; `0` = the firm states there is none, `null` = not published |

`changes` lists rule changes the firms published, newest first, with the program ids they affect.

## Example

```sh
jq '.firms[] | select(.id == "topstep") | .programs[].accounts[] | {name, maxDrawdown, drawdownMode, dailyLossLimit}' prop-firm-rules.json
```
